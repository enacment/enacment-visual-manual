# Enacment Visual Identity Manual

Public, static consultation site for the approved Enacment visual identity base.

SharePoint is the system of record for releases, source documentation, approval records, evidence, and prior versions:

<https://emtdevhouse.sharepoint.com/sites/EMTDevHouse/Documentos%20compartidos/Imagen/Sistema%20Visual%20Enacment>

This repository contains only the consultable manual (`index.html` and `tokens.css`) plus the public brand SVGs and IBM Plex font files needed to render it. The approved base is stable; the web, product, commercial, and social profiles continue to evolve under Ivy.

No analytics, external scripts, evidence files, source documents, release ZIPs, or credentials are included.

Serve the directory with any static HTTP server, for example:

```sh
python3 -m http.server 8000
```
